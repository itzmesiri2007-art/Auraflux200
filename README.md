# 💊 Dosewell

A smart medicine reminder and medication-management web application designed to help users organize their medicines and stay consistent with their medication schedules.

## 🌐 Live Demo

**Live Website:** https://auraflux200.vercel.app/

## 📌 About Dosewell

**Dosewell** is a modern web application focused on making medicine management simple, organized, and convenient.

The application helps users manage their medication information and keep track of their medicine schedules through an easy-to-use interface.

## ✨ Features

* 💊 Medicine management
* ⏰ Medication reminders and scheduling
* 📋 Organized medicine information
* 📱 Responsive and user-friendly interface
* 🧭 Easy navigation
* 🔐 Supabase integration for backend functionality

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/itzmesiri2007-art/Auraflux200.git
```

### Navigate to the project

```bash
cd Auraflux200
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
